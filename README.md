# STACK CRAFT — инструкция к проекту

## Структура

```text
stack-skeleton-modular/ 
├── index.html
├── services.html
├── info.html
├── contacts.html
├── assets/
│   ├── css/
│   │   ├── base.css                  # переменные, reset, container, общая сетка
│   │   ├── components/
│   │   │   ├── header.css            # шапка + мобильное меню
│   │   │   ├── footer.css            # футер
│   │   │   ├── placeholders.css      # заглушки и базовый текст
│   │   │   └── section-head.css      # заголовок секции в две колонки
│   │   └── pages/
│   │       ├── home.css              # только главная
│   │       ├── services.css          # только услуги
│   │       ├── info.css              # только информация
│   │       └── contacts.css          # только контакты
│   └── js/
│       └── main.js                   # открытие/закрытие мобильного меню
```

## Где находится вёрстка HTML страниц, JS файлы?

Вёрстка HTML страниц находится вне папок в главной директории проекта
JS файлы находятся по пути assets/js (**для каждого скрипта должна быть своя отдельная папка!**)

## Структура написания контента в HTML страницах

Контент на страницах выполнен в точности как и в дизайне на Figma без каких либо отклонений

## Где менять стили? 

Если меняется шапка - `components/header.css`.

Если меняется только страница услуг - `pages/services.css`.

Если нужно поправить ширину всего сайта, фон или общие переменные — `base.css`.

Адаптив каждого элемента лежит в том же файле, что и сам элемент. Например мобильная сетка услуг находится в `pages/services.css`, а мобильное меню — в `components/header.css`. 

## Как правильно начать работу с проектом? 

Перед началом убедитесь, что весь проект на месте и ни одна папка не потерялась.
Изучите каждый файл, попытайтесь понять мысль и то, что уже написано.
Поймите куда и что Вы хотите добавлять
Убедитесь, что Вы правильно действуете и изменяете именно то, что нужно изменять

---

**Нельзя после переноса проекта в редактор сразу же начинать работу с кодом не изучив проект!**
